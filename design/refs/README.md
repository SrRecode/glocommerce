# Design references

Drop reference images here (Pinterest / Dribbble / screenshots) before Phase 0 review.

Guidance for what is useful:

- Full-page screenshots of storefronts you like (layout, not just colors).
- Product card and product detail treatments.
- Admin table / dashboard screens you find readable.
- Anything showing typography or spacing you want matched.

Name files descriptively, e.g. `storefront-hero.jpg`, `admin-orders-table.png`.
The design system in `docs/DESIGN.md` is derived from these — keep this folder and that
document in sync so later phases have one source of truth.
